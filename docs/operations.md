# CYBER FIRST STEP：公開運用の詳細

日常の編集・起動方法は [README](../README.md)、問題の変更方法は [運用・編集ガイド](maintenance.md) を参照してください。この資料は素材の出典・公開設定・計測・運用上の制限を補足します。

防衛省サイバーコンテスト参加促進企画を元にした、学生企画の体験サイトです。防衛省の公式サービスではありません。

## 完成した機能

- 登録・アプリ導入不要の８問。暗号２問、画像２問、証拠探索２問、時系列１問、メール調査１問。
- 全問に無料の２段階ヒント、解説、学習内容。
- 画像の拡大、変更前後の切り替え、証拠カードの選択、上下ボタンによる並べ替え。
- サーバーで回答を判定。大文字小文字・全角英数字・前後空白を正規化。
- 正解と「解説で学習」を分けて表示。ヒント使用は減点なし。
- 改ざんを検知する署名付きのHttpOnly Cookieで進捗を30日保存。
- 練習を解かなくても公式大会案内に進める導線。
- 明るい背景と濃淡を付けたカード、濃いネイビーの本文、アクセント #AB431E。スマホ・タブレットの縦横画面に対応。配色は `public/theme.css` で管理。
- 初心者向けに合言葉（フラグ）と遊び方を問題一覧の前で説明。ヒントは全問でフラグ提出欄の下に配置し、無料・減点なしを明記。
- 背景は白に固定し、切り替えスイッチはありません。以前の暗い背景の保存設定も参照しません。本文・補足・操作ボタンは太字で表示します。
- 正解時はライとチェックマーク・紙吹雪、不正解時はリイと再挑戦の案内を表示。端末の「動きを減らす」設定に対応し、進捗復元時は演出を再生しません。

## マスコット素材

ライ・リイの紹介元は [防衛省サイバーコンテスト](https://www.mod.go.jp/j/approach/defense/cyber/c_contest/) です。`public/assets/rai-rii-cutout.png` はユーザー提供画像をもとに imagegen で背景と説明文字を除いた加工素材で、公式配布の透過データそのものではありません。サイト内の応援メッセージは学生企画で作成したものです。非公式の表記と素材の説明をトップ・紹介ページに掲載しています。

## 起動

Node.js 24を用意し、このフォルダで初回に `npm ci` を実行します。実行時依存パッケージはありません。

```text
npm run dev
```

ブラウザで http://127.0.0.1:3000 を開きます。ローカル用の署名鍵は初回に `.env.local` に保存され、サーバー再起動後も以前の進捗を維持します。鍵を変更・削除すると以前の進捗は無効になります。

```text
npm test
npm run build
```

## Android・iOS・タブレット向けの調整と検証

- ノッチやホームインジケーターの余白に対応。画面の拡大操作は制限しません。
- タブレット縦表示は本文を広く取り、ミッション一覧を開閉式にします。
- 本文16px相当、入力欄18px以上、主要操作44px以上のタップ領域。文字を200%に拡大した条件でも確認しています。
- 画像表示は画面の高さに収め、背景スクロールを止めます。拡大画像の上下左右スクロール、回転後の閉じる操作に対応します。
- 日本語入力の変換中のEnterで誤送信しない処理、連続送信の抑制、通信切断・12秒のタイムアウト後の再操作を用意しています。
- ブラウザから戻った場合の進捗再取得、画面切り替え中のリセット応答、本文へのスキップリンクを修正しました。

ローカルサーバーを起動した状態で、以下を別のターミナルで実行すると端末向けの回帰チェックを再実行できます。Playwrightは開発時だけの依存です。

```text
npm ci
npx playwright install chromium webkit
npm run test:devices
node tests/feedback.mjs
```

Chromium・WebKitで、13条件×11画面、画像拡大・縦横切り替え、回答・ヒント・解説・復元・リセット、通信切断後の復帰を検証します。結果は `test-results/device-report.json` に保存します。ローカルサーバーでも公開環境と同じCSP等のヘッダーを使用します。WebKitのスクリーンショット取得はテストツール自身が一時的なインラインCSSを注入するため、CSPエラーの検証から分けています。

これはWindows上のブラウザエンジン・画面条件での検証です。物理Android、iPhone、iPadのOSキーボード、実際のノッチ、ブラウザのツールバー、低メモリ時の動作は実機確認が必要です。FirefoxのWindows自動化は検証環境で新しいページ作成が停止したため、今回の合格対象に含めていません。

公開後は `node tests/published.mjs` で、公開URLの匿名アクセス、公開APIの回答非公開、Chromium・WebKitのタッチ回答・全角入力・進捗復元・画像の拡大・回転・タブレット配置を再確認できます。2026-10-06の公開版で合格しています。検証記録は `docs/公開モバイル検証記録.json` です。Windows WebKitのCookie検査はSameSiteをNoneと報告するため、SameSite=Strictは実際のHTTPS応答ヘッダーとChromiumのCookie検査で確認しています。

公開素材は `public/`、公開ビルドは `dist/`、問題と正解の管理はmicroCMS、判定は `server/game.mjs`、Vercel Function入口は `api/game.js` です。

## Vercel

- Framework：Other / null
- Build：`npm run build`
- Output：`dist`
- 公開環境の `CTF_SESSION_SECRET` に、32文字以上の十分ランダムな値を設定すること。
- `CTF_SESSION_SECRET` は公開素材、Git、READMEに保存しない。
- 署名鍵を変更すると既存の進捗は無効になります。
- APIだけでなくトップ、全問題、画像、Cookie、レスポンスヘッダーを公開後も確認する。

サーバー用ファイルや問題の正解一覧を `public/` や `dist/` にコピーしないでください。画像内の文字など、解くための手がかりは公開素材です。

## 更新方法

1. microCMSの「問題」で文章・正解・ヒント・解説・画像を編集し、公開する。
2. `npm run check` で入力形式と既存画像を確認する。
3. スマホで素材・ヒント・正答・誤答・解説・進捗を確認する。

問題データの変更は参照先のサイトに通常30秒程度で反映されます。問題内容の変更時には既存進捗が自動でリセットされます。表示コードの変更時はテスト・ビルド・再公開を行います。問題の内容や所要時間は初心者テストで調整してください。表示した時間は目安で、10〜20人による実測はまだ行っていません。

## 広報別の計測

公開URLに `?source=school`、`?source=x`、`?source=event` を付けると、学校・X・イベントを区別できます。何も付けない場合はdirectです。

サーバーログに `type: ctf_event` のJSONイベントを出力します。開始(start)、問題表示(view)、正解(solve)、解説による学習(learn)、ヒント(hint)、８問の体験完了(complete)、大会案内クリック(official_click)です。イベントにはIP・氏名・メール・回答内容・セッションIDを出力しません。

この版には全体集計のダッシュボードや独自データベースを追加していません。Vercelの運用ログの保持期間内でイベント別・媒体別に集計できます。長期３年の集計には、公開運用前にログの保存先と保存期間を別途整備してください。同じブラウザの進捗に基づくイベント抑制は、人数の厳密な重複排除ではありません。新しいCookie・別端末・並行操作で重複し得ます。

大会案内クリックは応募完了ではありません。応募数は主催者の集計が別途必要です。QR経由のアクセスは、カメラによる読み取り総数そのものではありません。

## 運用と限界

- Cookieは署名による改ざん検知を行いますが暗号化はしていません。個人情報は入れていません。
- 回答には短時間の連続送信制限があります。Cookieを捨てたアクセスまで防ぐ全体的なレート制限ではありません。一般向け広報を大規模に行う際は、Vercel側のFirewallや料金アラートも対象負荷に合わせて設定してください。
- Cookieの進捗は同じブラウザ用で、別端末への同期・アカウント・ランキングはありません。結果画面からリセットできます。
- 集計JSONに個人識別情報を含めなくても、ホスティング基盤のアクセスログにはIPなどが含まれ得ます。保存期間・権限・利用目的は公開運用主体で決定してください。
- 異常時はVercelで公開停止または過去のDeploymentへ戻し、問題を修正して再公開します。ホスティングログでAPIの503とサービス障害を確認できます。
- 実機のSafari/Chrome、初心者テスト、想定同時利用数による負荷試験は、学校・イベント等で大規模運用する前に実施してください。
- 第三者サイトの攻撃を行う課題ではありません。模擬ターミナル等のPC版は含みません。
- 公式サイトへのリンクは提供しますが、公式ドメイン・ロゴ・募集状況・応募受付を代理で運用していません。
- 企画書のCloudFront見積りは、このVercel版の契約料金には適用しません。
