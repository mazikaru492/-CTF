# CMS移行後の整理

利用者の指示は、動作と表示への影響を避けて旧問題データと不要ファイルを削除すること。

## 判断

- 本番コードの問題文・答えはCMSへ一本化する。
- 既存8問のテストデータは回帰確認に必要なためtests/fixturesへ移す。配信・起動・ビルドから参照しない。
- 既存画像の許可パスと旧進捗の互換性は、本文を含まない画像一覧・指紋・版番号で維持する。
- CSSとブラウザー側の表示コード、使用中の画像は変更しない。
- 既存の未コミット変更を保護するため、隔離した作業コピーで実装・検証し、元ファイルのハッシュが一致したものだけ反映する。コミット・プッシュ・公開は行わない。

## 手順

- [x] CMSが既定の唯一の読み込み元となる回帰テストを先に失敗させる。
- [x] サーバー・チェック・ビルド・テストの旧データ依存を整理する。
- [x] 移行専用生成処理・生成済みCSV/JSON・元のcontent/questions.jsonを削除する。
- [x] 自動テスト、ビルド、実CMSのデータ・公開レスポンス・画像・既存進捗を比較する。
- [x] 元プロジェクトへ反映し、Chromeで実表示と操作を確認する。

## 確認記録

作業前に公開レスポンス、1問正解済みの進捗Cookie、配信元ファイルの指紋を一時保存。秘密情報をログや成果物に掲載しない。

最終確認。自動テスト44件、実CMSチェック、ビルド、整形、差分検査が成功。実サイトの問題レスポンス・全8問の採点と解説・削除前の進捗Cookieを照合し、一致を確認。public配下28ファイルはバイト単位で変更前と一致。Chrome幅320・390・430pxで全8問の素材表示と横はみ出しなしを確認し、比較画像の切り替え・150%拡大・既存8問正解の進捗維持を確認。ブラウザー警告・エラーなし。配信28ファイルにAPIキー・進捗署名鍵なし。別担当の読み取りレビューでも重要な指摘なし。

削除した本番・移行用ファイルはcontent/questions.json、scripts/prepare-microcms.mjs、migration/microcms-questions.csv、migration/microcms-schema.json。回帰テスト用の元8問はtests/fixturesに保持し、本番配信対象外。使用中画像は保持。接続設定と署名鍵は維持。公開・コミット・プッシュは未実施。確認用サーバーは http://127.0.0.1:3108 。実スマホでの確認と新規CMS画像アップロード後の確認は今回未実施。
