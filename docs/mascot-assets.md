# ライ・リイの素材

背景と文字を除いた追加の透過素材9点は、[透過素材一覧](mascot-cutouts.md)に保存しています。サイト用PNGと高解像度版、背景を変えた確認画像、出典と加工記録をまとめています。

## 場面に合わせた配置

2026年11月10日、保存済みの透過素材を画面内に配置しました。訪問者の操作を助ける場所で使い、問題の手がかりや入力欄、ボタンの上には重ねません。画像には縦横の寸法と表情・動作を含む代替テキストを設定しています。画面下の案内画像は遅延読み込み、入口と結果・回答直後の画像は即時読み込みです。

| 場面                   | 配置する姿                 | 訪問者に伝える役割                        |
| ---------------------- | -------------------------- | ----------------------------------------- |
| トップの入口           | 手を振るライとリイ         | 歓迎して、一緒に挑戦する相手を紹介する    |
| 遊び方・ヒント         | 指示棒で案内するリイ       | 操作や考え方を教える場所だと伝える        |
| 正解した問題           | ジャンプするライまたはリイ | 発見を喜ぶ。問題ごとに2人を交代で表示する |
| 自力で全問正解した直後 | 2人でジャンプ              | 全問正解を特別な達成として祝う            |
| 解説で学ぶとき         | 穏やかに手を振るリイ       | 正解扱いの祝福はせず、一緒に学ぶ          |
| 途中の結果・復習       | パソコンを囲む2人          | 進捗を振り返り、次の挑戦を応援する        |
| 全問正解の結果         | ハイタッチする2人          | 達成感を強める。既存の祝福画像を維持する  |
| 不正解                 | 考えながら再挑戦を促すリイ | 既存の穏やかな応援を維持する              |

灰色に陰った困り顔や、謝るライは、誤答した人を責めたり「自分が謝るべき」と感じさせたりする可能性があるため、今回の学習場面には配置していません。保存素材としては引き続き管理しています。飾りを問題一覧の各カードや調査素材内に並べることも避けています。

制作プロンプトの要点：

- 共通：公式の2Dちびキャラの頭身、線、衣装、色を維持。全身・耳・しっぽを画面内に収める。透明背景。吹き出し、追加の文字、背景、透かしは付けない。
- ライ：`c-contest-01.png` を参照。紺色の髪、緑・青・水色の前髪、白いパーカー、紫の袖口、胸の `1337`、紺のズボンと靴を維持。正解を喜ぶ大きな笑顔、喜びで細めた目、片手はサムズアップ、もう片手は軽く上げる。
- リイ：`c-contest-02.png` を参照。白いボブと巻いた前髪、水色の四角い模様がある猫耳、青・水色の瞳、頬のひげ模様、水色のパーカー、紺のスカート、水色の足、白と水色のしっぽを維持。少し首をかしげて頬に指を添え、もう片手を開く。少し考える眉とやさしい微笑み。怒り、泣き顔、責める表現は避ける。
- 全問正解：上記2点を同一性の参照、`c-contest-04.png` を動きの参照とする。横長3:2。左にライ、右にリイを同じくらいの大きさで配置し、笑顔で跳びながら内側の手でハイタッチ。体・手足・しっぽを分離し、全体を収める。トロフィー・紙吹雪・星は画像に描き込まず、画面側の既存の紙吹雪を使用。

動きを減らす設定でも画像・文言は表示し、紙吹雪だけを停止する。正解数は問題数と比較するため、問題数変更にも追従する。
